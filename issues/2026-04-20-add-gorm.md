## Problem

The Go server was still using direct SQLite access only, but the project needed GORM available for upcoming persistence refactors.

## Solution

Added GORM and the SQLite driver to `tincan-server`:

- `gorm.io/gorm`
- `gorm.io/driver/sqlite`

Then ran:

- `go mod tidy`
- `go build ./...`

## Notes

This change only adds the dependencies.
It does not yet migrate the current conversation persistence code to GORM.
